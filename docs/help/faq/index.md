# 故障排查

本专题隶属于 [避坑与故障](/help/)，包含以下核心三级内容集群：

### [节点全部超时](/help/faq/timeout/)
> 节点全红、全部 Timeout、无法连接服务器，从本地到骨干网 10 步精准排查。

### [订阅更新失败](/help/faq/subscribe-fail/)
> 订阅链接失效、拉取为空、提示 0KB 与证书无效，全方位修复订阅拉取问题。

### [连接失败排查](/help/faq/connect-fail/)
> 软件显示已连接但网页打不开、DNS 污染、系统代理失灵与浏览器报错。

### [速度慢与晚高峰](/help/faq/slow/)
> 晚上 8~11 点卡顿、油管自动降画质、运营商 QoS 限速与网络优化技巧。
