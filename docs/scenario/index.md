## 核心专题导航矩阵

### 1. AI 研发与大模型 (`/scenario/ai/`)
针对严苛风控与开发者调用的高纯净度解决方案：
- **[3.1.1 ChatGPT 机场推荐](/scenario/ai/chatgpt/)**：原生解锁 OpenAI 官网与 API、彻底解决 Access Denied / 1020 报错、Voice 实时语音模式低延迟专线。
- **[3.1.2 Claude 机场推荐](/scenario/ai/claude/)**：秒过 Anthropic 极端风控、纯净原生/住宅 IP 节点、账号防秒封与 Pro 订阅绑卡技巧。
- **[3.1.3 Gemini 机场推荐](/scenario/ai/gemini/)**：Google AI Studio 百万上下文开发调试、Gemini Advanced 订阅与地区限制破局。

### 2. 海外超清流媒体 (`/scenario/streaming/`)
大带宽、高吞吐、零转圈的极致视听盛宴：
- **[3.2.1 Netflix 机场推荐](/scenario/streaming/netflix/)**：原生解锁非自制剧、4K HDR / 杜比视界支持、同户家庭限制破局。
- **[3.2.2 YouTube 机场推荐](/scenario/streaming/youtube/)**：秒开 4K/8K 超清、详细统计信息跑满 20万+ Kbps、晚高峰防降画质。
- **[3.2.3 TikTok 机场推荐](/scenario/streaming/tiktok/)**：跨境电商出海、免拔卡刷视频、直播推流防断流、破局 0 播放难题。
- **[3.2.4 流媒体解锁机场](/scenario/streaming/all/)**：Disney+、HBO Max、Amazon Prime 与英国 BBC iPlayer 全平台大满贯。

### 3. 外服游戏与海外社媒 (`/scenario/game/`)
超低物理延迟与全天候后台稳定保持：
- **[3.3.1 游戏加速机场](/scenario/game/accel/)**：UDP 转发满血支持、Steam/Epic 联机低延迟、Apex 与电竞抗丢包专线。
- **[3.3.2 社交平台机场](/scenario/game/social/)**：X (Twitter) 高清图片秒开、Telegram 解决一直 Connecting、Instagram 刷流与 WhatsApp 外贸防封。
