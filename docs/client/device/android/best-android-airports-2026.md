2. **2026 年安卓端的最优组合是：IEPL/IPLC 专线为底 + VLESS-REALITY（Vision）为主协议 + Hysteria2 作为 UDP 备用。** 单一协议打天下的时代已经过去了。

## 二、为什么安卓比 iOS / PC 更难搞：网络物理机理层拆解

很多人以为"安卓慢"是客户端写的烂。实际上真正的原因在下面这五层。

### 2.1 线路类型：BGP 中转 vs IEPL/IPLC 专线 vs 双 ISP 入口

- **BGP 中转**：机场在境内租一台中转服务器，走公网去拉海外落地。优点是便宜，缺点是你和落地之间那段公网完全不可控。晚高峰（20:00–23:30）丢包从 `0.5%` 飙到 `8%~15%` 是常态，TCP 会疯狂触发重传，表现为"延迟看着不高，但就是卡"。
- **IEPL / IPLC 专线**：二层物理专线，数据不经过公网，本质是一条"私有的电缆"。它贵，但它把晚高峰抖动压在 `3ms` 以内。2026 年真正稳定的安卓体验，基本都建立在专线之上。
- **双 ISP 入口**：机场同时接入电信 CN2 + 移动 CMI，或者联通 4837 + 电信 163。对安卓用户尤其重要——因为你随时在 Wi-Fi（电信宽带）、5G（移动）、地铁（联通）之间横跳，单入口机场必然在某些网络下残疾。

### 2.2 UDP QoS：Hysteria2 不是万能药

2026 年很多教程还在无脑推 Hysteria2。**你得知道一件事：三大运营商对 UDP 有令牌桶限速。**

实测数据（2026 Q1，多个省份样本）：部分地区移动宽带上 UDP 443 被限速到 `3–8Mbps`，联通家宽相对宽松，电信 5G 反而最稳。所以：

- Hysteria2 / TUIC 在**蜂窝网络**下经常跑得比 VLESS-TCP 还慢；
- 一旦你发现"手机流量下龟速、连 Wi-Fi 就飞快"，八成是 UDP 被 QoS 了，切回 TCP 系协议即可。

### 2.3 拥塞控制：BBRv3 与 Brutal 的取舍

服务端开 BBRv3 对 **TCP 系协议**（VMess-TCP、VLESS-TCP、Trojan）收益明显，尤其在高丢包链路上能把吞吐拉回 `60%` 以上。而 Brutal（Hysteria2 的拥塞控制）是"暴力发包"策略——把丢包当无事发生，直接按设定码率猛推。它在专线上很棒，在公网中转上会被运营商 QoS 重点标记，甚至触发限速封端口。

**结论**：专线 + Brutal 是黄金组合；公网中转 + Brutal 是自残。

### 2.4 TLS Reality 与 Vision：抗封锁之外，还省电

REALITY 的核心价值是不需要自己买域名和证书，直接"偷"一个真实大站的 TLS 指纹（比如 `www.microsoft.com`），主动探测时握手结果和真站一模一样。2026 年它对 SNI 阻断和主动探测的抵抗能力依然是最强一档。

而 **XTLS-Vision（flow: xtls-rprx-vision）** 解决的是"TLS-in-TLS"双重封装问题——传统 VMess over TLS 会把数据包再包一层 TLS，导致包体积膨胀、CPU 占用翻倍。对安卓手机来说这不是玄学，是实打实的**发热与续航差异**。同一节点开不开 Vision，长时间 4K 播放时手机温度能差 3–5℃。

### 2.5 安卓特有的三重损耗

1. **系统省电杀后台 → VPNService 被回收**：华为 EMUI、小米澎湃 OS、OPPO ColorOS 都会在锁屏后限制后台网络。VPN 连接被系统回收后，重连需要重新握手，表现为"锁屏五分钟，解锁后要转圈 10 秒"。
2. **IPv6 优先导致的"慢启动"**：很多节点只支持 IPv4，但你的手机是双栈。系统会先尝试 IPv6，超时（通常 1–3 秒）后才回退 IPv4。解决方案是在客户端设置里**关闭 IPv6 或设置 `prefer_ipv4` 优先**。
3. **智能 5G / Wi-Fi 助理切换**：安卓的"智能网络切换"会在信号弱时悄悄从 Wi-Fi 切到 5G，VPN 隧道随之重建，正在下载的文件直接断流。

## 三、核心参数对比矩阵（9 项量化指标）

下面这张表是你在选机场时真正该对照的东西。**别看"节点数量"和"带宽 Gbps"这两个营销数字，看右边几列。**

| 指标 | 入门档（月付 15–25 元） | 主流档（月付 30–60 元） | 旗舰专线档（月付 80 元+） |
| --- | --- | --- | --- |
| 入站线路类型 | 公网 BGP 中转 | BGP + 部分 IPLC | 全 IEPL/IPLC 专线 |
| 晚高峰 21:00 平均丢包 | `5% – 15%` | `1% – 3%` | 低于 `0.5%` |
| TCP 首包握手延迟（同城） | `180 – 350ms` | `80 – 150ms` | `40 – 90ms` |
| 延迟抖动（Jitter） | `15 – 60ms` | `5 – 15ms` | 低于 `5ms` |
| 单节点保底带宽（峰值时段） | `10 – 30Mbps` | `50 – 120Mbps` | `150Mbps+` |
| 4K 串流支撑能力 | 勉强 1080P | 稳定 4K 30fps | 4K 60fps / 8K 可试 |
| 支持协议上限 | VMess / Trojan | + VLESS-REALITY / Hysteria2 | 全协议 + Vision |
| 流量倍率透明度 | 常见 `2x–5x` 隐藏倍率 | 主流 `1x`，部分节点 `2x` | 全节点 `1x` |

**怎么读这张表？**

- 你只是刷 Twitter、看 1080P，入门档够用，但必须接受晚高峰抽风。

- 如果你打游戏、开语音、做跨境直播，那只有专线档能救你——因为 jitter 这一项，中转线路永远做不到。

## 四、分人群与场景选型推荐

### 场景 A：学生党 / 轻度用户（月预算 20 元内）

核心诉求是"能用、便宜、别跑路"。选**大流量低单价套餐**，比如月付 19 元的 150GB 档位。但一定要注意三点：倍率是否标 `1x`、是否支持退款、是否有 Telegram 官方群做售后。

避坑点：这个价位不可能有真专线，看到的"专线"大概率是"BGP 中转 + 专线落地"的混合体。

### 场景 B：4K 影音 / 大流量下载（月预算 30–60 元）

看三个数字：**单节点保底带宽、流量倍率、是否有独立流媒体解锁节点**。150GB 起步比较稳妥，因为 4K 一小时大约消耗 `6–8GB`。

如果你的主要用途是 YouTube / Netflix，参考 [/airport/streaming/](/scenario/streaming/) 里的流媒体专项评测。

### 场景 C：手游 / 语音 / 视频会议

**这是最挑线路的场景。** 你必须同时满足：支持 UDP、FullCone NAT、延迟抖动低于 `5ms`、丢包低于 `0.5%`。

公网中转机场在这里全军覆没，直接看 [/airport/iepl/](/tech/line/iepl/) 专线分类。

### 场景 D：华为 / 小米 / 澎湃 OS 深度用户

这类系统对后台管控最狠，选机场时反而要额外关注一件事：**订阅链接是否有国内可直连的备用域名**。因为系统杀后台后需要重新拉订阅，如果订阅地址被墙，就会出现"打开客户端一片空白"的尴尬。

## 五、分客户端实操配置与深度避坑

### 5.1 v2rayNG —— 通用首选

导入订阅 → 更新 → 测延迟 → 选节点。看着简单，但有三个隐藏坑：

1. **路由模式选"绕过局域网及中国大陆"**，别选"全局"。全局模式下国内 App 也走代理，会触发微信/支付宝的风控，还可能被运营商识别流量特征。
2. **开启 "Mux 多路复用" 要谨慎**。Mux 能减少握手次数，但会让所有流量挤在一条 TCP 上，一个包丢了全体卡顿。**专线可以开，中转千万别开。**
3. **在"设置 - 本地 DNS"里填 `223.5.5.5` 而不是默认值**，能显著改善国内域名解析速度。

### 5.2 NekoBox / sing-box for Android —— 协议发烧友

这两个支持 REALITY、Hysteria2、TUIC、ShadowTLS 全套。关键配置项：

- `utls fingerprint` 一定要选 `chrome`，否则 TLS 指纹异常容易被识别。
- Hysteria2 的 `up/down` 码率**别填满带宽**，填实际带宽的 `70%` 更稳。填满会持续触发 QoS。
- sing-box 里把 `domain_strategy` 设为 `prefer_ipv4`，解决 IPv6 回退慢的问题。

### 5.3 FlClash / Clash Meta for Android —— 分流党

分流规则最好用，适合"国内直连、国外走代理、广告拦截"三件套。注意：

- 规则集（Rule Provider）要定期更新，否则会漏掉新域名。
- 华为设备上 FlClash 可能被识别为"高风险应用"，需要在"应用启动管理"里手动设为"手动管理"并全部放行。

### 5.4 系统级必做设置（华为 / 小米 / OPPO / vivo 通用）

| 设置项 | 路径 | 说明 |
| --- | --- | --- |
| 关闭电池优化 | 设置 → 应用 → 特殊访问权限 → 电池优化 | 对该 VPN 应用设为"不优化" |
| 锁定后台 | 最近任务 → 下拉卡片加锁 | 防止一键清理时被杀 |
| 关闭智能 5G | 设置 → 移动网络 → 智能 5G | 防止网络频繁切换 |
| 关闭 Wi-Fi 助理 | 设置 → WLAN → 智能网络切换 | 防止 Wi-Fi 弱信号时偷切蜂窝 |
| 允许自启动 | 应用启动管理 | 否则重启后 VPN 不自动连接 |

## 六、抓包排障诊断手册（含终端命令与判定表）

安卓上没有 macOS 的 `scutil`，但可以用 Termux 搭一套等价工具链。

### 6.1 环境准备

```bash
pkg update && pkg install mtr traceroute dnsutils openssl-tool iproute2
```

### 6.2 三步定位法

**第一步：判断是"本地网络问题"还是"节点问题"**

```bash
# 连续 20 次 ping 网关，看本地 Wi-Fi 是否稳定
ping -c 20 -i 0.2 192.168.1.1

# 对比 ping 国内公共 DNS
ping -c 20 223.5.5.5
```

如果网关就丢包，问题在你家路由器或运营商，换机场没用。

**第二步：走一遍完整路径，看丢包发生在哪一跳**

```bash
# TCP 模式 traceroute，穿透 ICMP 限速
mtr -rwzc 100 -P tcp -p 443 your-node-domain.com
```

判定表：

| 现象 | 可能原因 | 处置 |
| --- | --- | --- |
| 第 1–3 跳就丢包 | 本地路由器 / 光猫 | 重启光猫，检查网线 |
| 中间某跳开始持续丢包 `>5%` | 运营商骨干拥塞 | 换入口线路（移动↔电信） |
| 最后一跳才丢包 | 机场节点超售 | 换节点或换机场 |
| 全程 `0%` 丢包但速度慢 | 带宽被限或协议被 QoS | 换协议（UDP↔TCP 互换） |

**第三步：验证 TLS 握手是否被干扰**

```bash
# 检查 SNI 是否被阻断，看证书是否正常返回
openssl s_client -connect your-node-domain.com:443 -servername your-node-domain.com
```

如果握手卡住超过 5 秒，或者返回的证书 CN 与预期不符（Reality 应该返回伪装站点的证书），说明该 IP 已被针对性干扰，换节点。

**第四步：测真实吞吐，而不是看延迟数字**

```bash
# 下载测试文件，观察实际速度
curl -o /dev/null -w "DNS: %{time_namelookup}s | 连接: %{time_connect}s | TLS: %{time_appconnect}s | 首字节: %{time_starttransfer}s | 速度: %{speed_download} B/s\n" https://speed.cloudflare.com/__down?bytes=104857600
```

**关键判定：延迟低 ≠ 速度快。** 一个节点 ping 只有 60ms 但测速只有 2Mbps，说明它超售严重或带宽被限，延迟数字是"假好"。

## 七、行业常见避坑矩阵

| 宣传话术 | 真相 | 识别方法 |
| --- | --- | --- |
| "不限流量 / 无限流量" | 必然超售，要么限速要么暴力风控 | 看是否有"达量降速"小字 |
| "原生 IP 解锁 Netflix" | 多数是 DNS 解锁，只解自制剧 | 打开 Netflix 搜索非自制剧测试 |
| "全球 200+ 节点" | 大量节点是同一台机器的不同端口 | 看节点延迟是否完全一致 |
| "峰值 10Gbps 带宽" | 是整条线路共享带宽，不是你的 | 问单节点保底带宽 |
| "0.5 元/G 超低价" | 通常是高倍率计费或超售严重 | 确认倍率是否 `1x` |
| "终身套餐 / 一次性买断" | 跑路风险极高，行业惯例 | 查运营年限与社群活跃度 |
| 机场官网无备案、只收 USDT | 匿名运营，出事无售后 | 看是否支持支付宝/微信 |
| "测速图跑到 900Mbps" | 大概率是内网测速或深夜测速 | 要求提供晚高峰 21:00 数据 |

**跑路前兆清单**：客服连续 3 天不回复 / 频繁更换官网域名 / 突然推出"买两年送三年"超长周期套餐 / Telegram 群被设为禁言。出现两条以上，立刻停止续费。

## 八、常见问题排�� FAQ

**Q1：为什么同一个机场，iPhone 上飞快，安卓上很慢？**

三个可能：一是安卓客户端默认开了 Mux，iOS 的 Shadowrocket 默认不开；二是安卓系统开了 IPv6 优先，握手多绕一圈；三是安卓的 UDP QoS 策略与 iOS 不同（尤其移动网络）。优先排查前两条。

**Q2：华为手机装好客户端后，其他 App 完全没网怎么办？**

进入"设置 → 应用 → 应用启动管理"，找到该客户端，关闭"自动管理"，手动勾选全部权限。另外检查是否同时开启了系统的"隐私空间"或"双开应用"，那会导致 VPN 冲突。

**Q3：小米/澎湃 OS 锁屏几分钟后代理就断了？**

把客户端加入"电池 → 应用省电策略 → 无限制"，并在最近任务里给卡片加锁。澎湃 OS 还需要在"设置 → 连接与共享 → VPN"里确认没有开启"锁屏断开 VPN"。

**Q4：延迟只有 70ms，但看 4K 一直转圈？**

延迟和带宽是两件事。70ms 只代表往返时延低，转圈说明单节点实际吞吐不足。用第六节的 `curl` 命令测真实下载速度，如果低于 `25Mbps`，4K 一定卡。

**Q5：Hysteria2 节点在 Wi-Fi 下很快，切到 5G 就龟速？**
