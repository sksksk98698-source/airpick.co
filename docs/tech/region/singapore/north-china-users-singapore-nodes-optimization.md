# 北方联通与电信用户连新加坡节点指南：跨省中转最佳落地实践

## 一、TL;DR：三句话先给结论

关于「北方用户连接新加坡优化」，网上绝大多数说法都在重复一个错误前提——**距离决定延迟**。实际上，北京到新加坡直线约 4400 公里，光纤往返理论下限在 60ms 左右，谁都突破不了；而你实测是 75ms 还是 220ms，**取决于出口选址，不取决于距离**。

三句话结论：

1. **物理下限 ≈ 60ms**，北京实测 72–85ms 属于优秀，超过 130ms 基本可以判定绕路（日本/韩国/美国中转）。
2. **北方 → 广州/汕头出口 → 新加坡** 是当下最优公网路径；北方 → 上海 → 香港 → 新加坡 往往多出 15–35ms。
3. **晚高峰丢包才是体感杀手**，不是带宽。20:00–23:00 的丢包率如果超过 3%，4K 和远程桌面都会崩，此时只有 CN2 GIA、联通 9929 或 IEPL/IPLC 能救。

**北方主要城市 → 新加坡 RTT 参考值**

| 出发地 | 理论下限 | 优质线路实测 | 绕日/绕美实测 |

读表方法：如果你的实测值落在第三列，说明链路正常；落在第四列，问题不在你的设备，在选路。

## 二、底层机理：一个包从北京到新加坡要闯几道关

**第一关：省网 → 骨干网。** 电信走 AS4134（163 骨干）或 AS4809（CN2），联通走 AS4837（169 骨干）、AS9929（CUII 精品）或 AS10099（CUG 国际）。北方各省的省网出口带宽和汇聚策略差异极大，这也是为什么同一个机场，北京和沈阳的体验能差 30ms。

**第二关：国际出口选址。** 中国大陆的国际出口大致分三簇：上海/青岛方向主要承载去美、去日的海缆（NCP、TPE、APCN-2）；广州/汕头/深圳方向承载东南亚与南亚（APG、AAG、SJC、SMW-5，以及 2024 年投产的 ADC 亚洲直达海缆，中国电信与联通均有参与）；香港方向则是最灵活的中转枢纽。

**关键点在于跨境策略点的数量。** 一个包每过一次边境关口，就要经历一次策略路由查询、流量清洗、DPI 分类和 QoS 标记。北京 → 上海 → 香港 → 新加坡是三次跨境策略点，北京 → 广州 → 新加坡直连海缆只要两次。少一次跨境，通常值 10–20ms 和 0.5–1.5% 的丢包。
