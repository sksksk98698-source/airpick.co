## 核心专题导航矩阵

### 1. 底层线路技术 (`/tech/line/`)
物理光纤链路、跨境中转与骨干网络传输：
- **[4.1.1 IEPL 机场推荐](/tech/line/iepl/)**：国际以太网专线，物理点对点内网通信、不过 GFW 审查、零丢包的旗舰标准。
- **[4.1.2 IPLC 机场推荐](/tech/line/iplc/)**：经典国际私有租用专线，三层点对点通信、历史悠久的硬核抗封锁方案。
- **[4.1.3 BGP 中转机场](/tech/line/bgp/)**：边界网关协议多线智能接入，三网平衡、大带宽低成本的中坚力量。
- **[4.1.4 CN2 GIA 机场](/tech/line/cn2-gia/)**：中国电信下一代承载网（AS4809）优质路由，美西洛杉矶 120ms 直连标杆。

### 2. IP 属性与纯净度分类 (`/tech/ip/`)
出口身份标识与海外风控防火墙应对：
- **[4.2.1 原生 IP 机场推荐](/tech/ip/native/)**：纯正当地注册机房 IP，彻底告别跨国机房广播段，流媒体与 AI 全绿。
- **[4.2.2 住宅 IP 与静态 IP](/tech/ip/residential/)**：真实家庭宽带民用 ISP 出口、独享静态长效 IP，跨境电商与防封号终极神选。

### 3. 全球核心地区节点 (`/tech/region/`)
根据物理地理位置与跨海光缆布局挑选：
- **[4.3.1 香港节点机场](/tech/region/hongkong/)**：低至 20ms 极限物理延迟，华南地区与中文流媒体首选枢纽。
- **[4.3.2 日本节点机场](/tech/region/japan/)**：华东直连 30ms，二次元追番、日剧 TVer 与日服电竞玩家专属极速通道。
- **[4.3.3 新加坡节点机场](/tech/region/singapore/)**：东南亚互联心脏，ChatGPT/Claude/TikTok 毫无限制的全能六边形战士。
- **[4.3.4 美国节点机场](/tech/region/usa/)**：全球互联网中枢，全片源首发、AI 技术发源地、大带宽平价节点聚集地。
