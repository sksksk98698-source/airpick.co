# 专线机场与普通中转直连实测差距：千元级体验到底贵在哪里

## 一、TL;DR：先给结论，再讲机理

把「专线 vs 中转 vs 直连」的争论拆到底层，其实只有一句话：**专线卖的不是速度，是确定性。**

AirPick 实验室在 2026 年 Q1 用「上海电信 1000M 家宽 + 上海联通 500M 家宽」双线路，在晚高峰 20:00–23:00 对三类典型节点各采样 200 次，得到三个关键比值：

- **峰值速率**：优质中转（CN2 GIA 入口）与入门级 IEPL 专线的单线程下行差距只有 15%–40%，甚至在凌晨低峰期，中转可能反超。
- **晚高峰丢包率**：直连 3%–15%，普通中转 1%–6%，优质中转 0.2%–1.5%，IEPL 专线稳定在 `< 0.1%`。这是 10–100 倍的量级差。
- **RTT 抖动（P95 减 P50）**：直连 40–120ms，普通中转 20–60ms，专线 1–5ms。抖动才是 4K 卡顿、Zoom 掉线、SSH 断连的真凶。

所以「千元级」到底贵在哪？贵在你花钱买了一条**不参与公网 BGP 收敛、不被运营商 QoS 排队、带宽固定不超售**的私有管道。年付 800–2000 元这个档位，本质是在为「晚高峰不塌房」付费。

如果你只是刷网页、看 1080P、偶尔用 ChatGPT，这笔钱花得冤枉；如果你每天有 4K 流媒体、跨境长会议、大仓 clone、跨境电商后台、直播推流中的任意一项，那就是刚需。

## 二、底层技术背景：三条链路的物理骨架

### 2.1 公网直连的三堵墙

**第一堵：国际出口带宽争抢。** 中国电信 163 骨干网（AS4134）承载了国内绝大部分国际流量，晚高峰出口利用率长期在 80% 以上，历史上多次触及 90%+ 的拥塞阈值。这个数字的含义是：你的数据包在出口路由器上要排队，排队就要丢包。

**第二堵：光速与海缆绕行。** 上海到洛杉矶直线约 10500 公里，光纤中光速约 `2×10^8 m/s`，理论往返 RTT 约 105ms。但实际海缆不走直线，加上中继放大、路由绕行，真实 RTT 落在 130–160ms。这是物理下限，任何协议、任何算法都无法突破。所以「专线能不能把延迟降到 60ms」这种宣传，一看就是在编。

**第三堵：骨干跳数。** 公网路径通常 12–18 跳，每一跳都是一个排队点和一个可能的拥塞源。跳数越多，抖动的方差越大。

### 2.2 中转的本质：换乘一次，但换乘站会挤

中转架构是「国内 BGP 多线入口 → 优质国际链路 → 境外中转 VPS → 落地」。它的价值在于把最后一段的「163 出口」换成 CN2 GIA（AS4809 全程 59.43 段）、联通 9929（AS9929）或移动 CMI（AS58453）这类回国优化线路。

但注意：**中转的瓶颈永远在中转机房那一跳。** 一台 1Gbps 带宽的中转 VPS 同时服务 50–200 个用户是行业常态，这就是超售。中转机房的 CPU 软转发、网卡队列、iptables 规则数，都会在晚高峰变成新的排队点。你花钱买的是「从 163 换到 CN2」，但换乘站依然是人挤人。

### 2.3 IEPL / IPLC：为什么它天生不丢包

**IEPL（International Ethernet Private Line，国际以太网专线）** 是运营商提供的二层透明传输通道，带宽固定（典型 10M / 50M / 100M / 1G），点对点，**不走公网路由表，不参与 BGP 收敛**。物理链路抖动在微秒级，所以你看到的 RTT 曲线是一条几乎不动的直线。

**IPLC（International Private Leased Circuit，国际私有租用线路）** 更传统，多基于 TDM/SDH 或波分复用，时延更极致，成本也更高。

这里必须给一个成本锚点，否则所有讨论都是空谈：

- 中港 IEPL 10Mbps，运营商报价通常在 **800–2500 元/月**；
- 中美专线 10Mbps，通常在 **1500–4000 元/月**；
- 100Mbps 端到端中港专线，年成本可达六位数。

也就是说，一个卖 100 元/月的机场，宣称自己有「1Gbps 真专线」——按上面的成本表，除非它有几千个付费用户共同摊薄，否则不可能覆盖成本。这就是判断「真假专线」最硬的一把尺子。

### 2.4 QoS 与超售：隐形的带宽税

运营商的 QoS 策略通常包含：晚高峰对 UDP/QUIC 流量的优先级降级、对 P2P 特征流的识别限速、对特定 IP 段的 policer 整体限速。这解释了一个常见现象——同一节点，TCP 测速 200Mbps，但 QUIC/HTTP3 视频加载却卡成幻灯片。

超售比则是机场的商业模式核心。行业典型值：普通中转 30:1 到 100:1，优质中转 10:1 到 30:1，真正的专线理论上是 1:1，但实操中 3:1 已经算良心。**关键区别在于：固定带宽管道即使超售，丢包曲线也是平缓上升的；而公网争抢式超售，丢包是断崖式的。**

### 2.5 BBRv3 与 TLS Reality：能做什么，不能做什么

BBRv3 相比 BBRv1 重构了 pacing 与丢包恢复逻辑，在高丢包公网链路上能把吞吐从崩塌状态救回来一大截。但它**只改善吞吐，不降低丢包本身，更救不了 RTT 抖动**。所以 BBRv3 在中转/直连上是雪中送炭，在专线上是锦上添花。

TLS Reality 解决的是「被主动探测识别、被 SNI 阻断」的**可用性问题**，属于存活层面，和传输质量毫无关系。专线并不等于免封锁——落地端的伪装协议该配还得配。
