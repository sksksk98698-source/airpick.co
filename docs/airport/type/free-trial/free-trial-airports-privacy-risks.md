## 一、TL;DR：先给结论，再讲道理

如果你只有 30 秒，请记住这四句话：

1. **要求绑定手机号、身份证、微信授权的"免费试用机场"，风险等级直接拉到最高。** 试用本身不值钱，你的实名身份信息才值钱。
2. **"0 元试用 + 强制绑卡"是订阅制收割的标准剧本。** 真正的风险不在试用期，而在你忘记取消后的自动续费，以及卡 BIN 数据被留存。

## 二、底层机理：从数据黑产链路到网络物理层，为什么"免费"必然有代价

### 2.1 数据侧的变现链路：一个手机号能卖多少次

一个"免费试用机场"如果把注册门槛设成手机号 + 短信验证码，那么它在拿到手的那一刻，就同时获得了三样东西：

- **确权信息**：手机号 + 验证码，证明这个号码是活人正在使用的（这比邮箱值钱得多）；
- **活跃画像**：能访问海外网络，有跨境需求，付费能力中等偏上——这是精准营销的黄金标签；
- **关联线索**：如果用户复用了同一密码，撞库（Credential Stuffing）就能顺藤摸瓜拿到邮箱、电商、甚至支付类账号。

行业里这类流量的批发价，活跃手机号线索是**每条 0.3–3 元**不等，带"已通过短信验证 + 有跨境网络需求"标签的价格可以再翻两三倍。一个日活 5000 的"免费试用"站，一个月能沉淀十几万条线索，而且成本只有几台中转机的带宽费。**你以为是你在白嫖机场，实际上是机场在白嫖你。** 这就是"免费梯子套取手机号"的完整商业闭环。

### 2.2 网络侧的物理机理：专线成本不允许"免费"

再看网络这一侧，成本结构是硬约束：

- **IPLC（国际私有专线）**：端到端独占电路，内地—香港方向的常见采购价在**每 Mbps 每月 60–150 美元**区间。换算一下，一个 1Gbps 的 IPLC 端口，光是月租就是数万美元级别，这不含机房机柜、电力和运维人力。
- **IEPL（国际以太网专线）**：本质是 IPLC 的以太网封装形态，支持点到点、点到多点，带 QoS 保障。价格同数量级，优势在于可以做带宽的精细切片与优先级调度。
- **BGP 中转**：国内中转机接入多线 BGP（电信 CN2、联通 9929、移动 CMI 等），再用隧道打到境外落地。成本远低于 IPLC，但**丢包和绕路不可控**，且中转出口的 QoS 策略由运营商单方面决定。

所以，一个宣称"免费试用、无限流量、4K 秒开"的节点，只有两种可能：**要么用的是超售到极致的普通 BGP 中转机（成本几分钱），要么这个节点本身就是个抓包探针**。没有第三种解释。

### 2.3 几个常被忽略的技术细节，恰好是"劣质试用"的技术指纹

- **QoS 与 UDP 限速**：运营商对高带宽 UDP 流普遍执行 QoS 降优先级。免费试用节点如果只有 TCP 能跑、QUIC（UDP 443）一开就断，多半是被 QoE 策略掐了，或者是上游根本没给够带宽。
- **BBRv3 拥塞控制**：在跨境高丢包链路上，BBRv3 相比 CUBIC 能把有效吞吐提升 2–5 倍。正规机场的服务端内核普遍已经启用；而廉价试用节点多数还在跑默认 CUBIC，表现就是"测速好看、看视频一直缓冲"。
- **TLS Reality / 无证书伪装**：2026 年主流抗封锁方案。它的特点是服务端不需要真实域名证书，通过借用目标站点的 SNI 完成握手伪装。**关键点在于：Reality 的正常使用完全不需要你提供任何身份信息**，任何以"抗封锁需要实名"为由索要身份证的说法，都是纯忽悠。
- **双 ISP / 原生 IP**：用于流媒体与风控场景的 IP 属性判定。真正的原生双 ISP 住宅属性 IP 成本极��（单 IP 月租可达数十美元）。那些宣传"全网解锁 Netflix 全区"却又不收费的节点，通常是机房 IP 伪装，登录三方流媒体大概率触发风控验证。

把这四点连起来看就非常清晰了：**正规机场的成本压力在带宽和 IP 资源上，它没有任何动机去收集你的手机号和身份证；只有把"用户数据"当成主营业务的站点，才需要免费。** 想进一步理解线路层级的差别，可以对照阅读 [IEPL 专线机场深度解析](/tech/line/iepl/) 与 [IPLC 专线机场选型指南](/tech/line/iplc/)。

## 三、四类"假试用"形态拆解与风险分级

### 类型 A：手机号 + 短信验证码注册（风险：极高）

标准流程：进站 → 点"免费领取 3 天" → 输入手机号 → 收验证码 → 领取 1GB 流量 → 第二天开始接到贷款、代购、境外保险的骚扰短信。

真实目的不是让你用，而是**号码确权 + 私域引流**。很多站点在验证通过后，会自动把你拉进 Telegram 群或企业微信，接下来的剧本就是"老带新返利""内部渠道折扣"。这类站点通常没有 ICP 备案、没有明确运营主体、页面模板和另外几十个域名完全一致——典型的一人多站批量运营。**看到"请输入手机号获取验证码"就关掉，这一条能避开八成坑。**

### 类型 B：0 元试用 + 强制绑定信用卡（风险：极高）

标准流程：绑定 Visa/Mastercard → 领取 7 天试用 → 到期自动续费年付 → 取消入口藏在三层菜单之外，或者干脆需要发邮件申请。

这里有两个技术层面的坑点：

1. **预授权（Authorization Hold）**：绑卡时部分网关会发起 1 美元验证性预授权，冻结额度并验证卡片有效性。即便你立刻取消，卡 BIN + 有效期 + 姓名已经被记录。
2. **订阅型代扣（Recurring Billing）**：只要你没有走完正式的取消流程，收单方就能按周期发起扣款。跨境争议（Chargeback）处理周期普遍在 30–90 天，很多人嫌麻烦就放弃了。

**判定标准很简单：如果"取消订阅"的按钮比"订阅"按钮更难找，那就是故意设计的。** 建议统一使用虚拟卡或一次性卡号，并把额度设为最低。

### 类型 C：Telegram / 群里"白嫖节点"（风险：中高）

这类节点通常以 base64 订阅链接形式散播。风险不在注册信息，而在**流量本身**：公共节点是天然的中间人聚集地，任何明文 HTTP 流量、DNS 查询都可能被记录。同时，公共节点被滥用后会迅速被目标站点风控，表现为"能连上但登录不了谷歌、ChatGPT 一直转圈"。

这类链接偶尔也确实是机场的拉新渠道，但比例极低且时效极短，通常几小时就失效。**当作临时应急可以，当作长期方案等于把隐私挂在公共晾衣绳上。**

### 类型 D：小额付费试用装（风险：低，推荐）

典型形态：¥3–¥15，包含 5–50GB 流量、1–7 天有效期，无需实名，支持支付宝/USDT，明确标注"不自动续费"。

这是唯一健康的试用形态。它同时满足三个条件：**商家能覆盖边际带宽成本、用户不需要交出敏感信息、双方都不承担长期绑定义务**。本站的 [免费试用与小额试用机场合集](/airport/type/free-trial/) 收录标准也是按这个来的。

## 六、分客户端 / 分平台实操配置与深度避坑

### 6.1 iOS（Shadowrocket / Stash / Surge）

- App Store 需要非中国区 Apple ID 才能下载，**不要**为了省事去淘宝买共享 ID，账号被锁的风险比隐私泄露更快发生；
- 导入订阅后，务必在「设置 → 全局路由」选择"配置/规则"模式，避免全局模式把国内 App 流量全部外发；
- iOS 的"本地网络"权限、"后台 App 刷新"会显著影响长连接稳定性，排障时先检查这两项；
- 详细教程见 [iOS 客户端配置手册](/client/app/shadowrocket/)。

### 6.2 Android（Clash Meta / sing-box / v2rayNG）

- 优先从官方 GitHub Release 下载，**拒绝任何第三方 APK 聚合站**——这是安卓端恶意 SDK 的主要投毒渠道；
- 开启「绕过局域网」「国内直连」规则集，避免本地 NAS、投屏、打印机等内网服务被代理；
- sing-box 的原生 TUN 模式比 VPNService 转发性能更好，但要注意电池优化白名单；
- 参考 [Android 客户端完整配置](/client/app/sing-box/)。

### 6.3 Windows / macOS（Clash Verge Rev / Mihomo Party）

- Windows 上优先使用 Clash Verge Rev 这类仍在活跃维护的分支，老版本 Clash for Windows 已停止维护，存在已知漏洞；
- macOS 建议启用 TUN 模式替代系统代理，避免部分 App 不遵守系统代理设置；
- 无论哪个平台，**订阅链接都不要截图发到群里**——订阅链接等于账号密码，泄露后可被任意盗用流量；
- 参见 [桌面端客户端选型与调优](/client/app/clash/)。

### 6.4 通用避坑清单

- 注册时使用**邮箱别名**（如 `yourname+airport@gmail.com`），便于溯源是哪家泄露了你的邮箱；
- 任何情况下都不要在同一个小众机场网站上使用你常用的主密码；
- 绑卡前确认支付通道是支付宝/微信/USDT，跨境卡代扣风险最高；
- 试用期结束前 24 小时设置日历提醒，不要指望自己记得。

## 七、抓包排障诊断手册：终端命令与判定表

当你怀疑"这个免费试用节点在搞事情"时，下面这套流程可以在 5 分钟内给出判断。

**第一步：查 DNS 是否被劫持**

```bash
# macOS
scutil --dns | grep -m5 nameserver
# Linux / Windows(WSL)
cat /etc/resolv.conf
```

本地 DNS 如果被指向了机场自建服务器，那么你所有的域名解析记录都在对方手里。

**第二步：查真实出口 IP 与 ASN**

```bash
curl -s https://ipinfo.io/json
curl -s https://1.1.1.1/cdn-cgi/trace | grep -E "ip=|loc="
```

对照节点宣称的"原生 IP / 双 ISP"，看 `org` 字段是不是机房 ASN（如 AS13335、AS9009 等），如果是，那"住宅属性"就是假的。

**第三步：链路质量与丢包定位**

```bash
mtr -rwzc 50 1.1.1.1
```

`-z` 会显示每一跳的 ASN，判断绕路和丢包发生在国内出口、国际段还是落地机房。

**第四步：TCP 层握手质量**

```bash
tcping -t 5 -c 20 你的节点域名 443
```

关注的是**抖动（jitter）**而不是平均值。平均 80ms 但抖动 ±60ms 的链路，体验会比稳定 150ms 差得多。

**第五步：证书与中间人检查**

```bash
openssl s_client -connect 节点域名:443 -servername www.cloudflare.com
```

重点看返回的证书颁发者。如果是自签证书或者陌生的私有 CA，说明这条链路具备完整的解密能力，**任何非 HTTPS 的流量都不安全**。

| 现象 | 最可能的原因 | 处置建议 |
| --- | --- | --- |
| 第 1–2 跳就出现持续丢包 | 本地 ISP 或家宽质量问题 | 换网络环境复测 |
| 中间某跳丢包但后段恢复 | 该路由器 ICMP 限速，属正常 | 可忽略 |
| 出口后全程丢包 10% 以上 | 中转机房拥塞或超售 | 更换节点或服务商 |
| 平均延迟正常但抖动剧烈 | 共享带宽争抢严重 | 避开晚高峰或换线路 |
| 证书颁发者为未知 CA | 存在中间人或自建 MITM | 立即停止使用该节点 |
| DNS 解析指向节点自身 | 解析流量被完全掌握 | 改用加密 DNS（DoH/DoT） |

这套流程配合 [网络排障工具箱](/help/faq/slow/) 使用，基本可以覆盖 90% 的"这节点是不是有问题"的判断需求。

## 八、行业避坑防骗矩阵

| 宣传话术 | 真实含义 | 验证方法 |
| --- | --- | --- |
| "永久免费，无限流量" | 成本不可能成立，数据即货币 | 看是否有充值入口、隐私政策是否涉及第三方共享 |
| "仅需手机号即可领取" | 号码确权引流，用于营销或转卖 | 换一次性虚拟号测试，观察后续是否被拉群 |
| "0 元试用，随时取消" | 订阅代扣，取消入口刻意做深 | 提交前先找"取消订阅"按钮在哪 |
| "原生 IP，Netflix 全区解锁" | 多数为机房 IP 伪装 | 用 `ipinfo.io` 查 ASN 类型 |
| "不限速不限设备" | 高倍率超售，晚高峰必崩 | 晚 20:00–23:00 做 4K 压力测试 |
| "上市公司背景 / 十年老牌" | 无工商信息可查的营销话术 | 查域名注册时间与 WHOIS 变更记录 |
