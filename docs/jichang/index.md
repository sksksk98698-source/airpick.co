## 三、避坑与防跑路原则

在购买任何机场前，请牢记以下三大防骗原则：
1. **警惕“永久终身会员”**：带宽与服务器均为按月高昂成本支出，凡宣称“199元永久无限量”均为跑路资金盘。
2. **新手坚持月付**：无论宣传多么天花乱坠，首月务必月付实测自家本地宽带（电信/联通/移动）的真实连接表现。
3. **保持至少一家备用**：重要生产业务或开会出海，建议常备一个 [按量计费不限时套餐](/airport/price/pay-as-you-go/) 随时兜底。
