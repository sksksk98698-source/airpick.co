## 📖 项目简介 (Overview)

**AirPick**（官方唯一域名：[airpick.co](https://airpick.co/)）是一个基于 **VitePress 1.6** 深度构建的高性能、现代化出海网络知识库与选型评测指南。

项目针对传统翻墙评测领域普遍存在的“虚假宣传、严重超售、断流跑路、软文泛滥”等痛点，联合网络架构工程师建立自动化全天候拨测机制，并基于 **DeepSeek-R1 深度推理模型** 全量打磨了 **432 篇**兼具底层计算机网络原理（IEPL/IPLC、BGP Anycast、BBRv3、TLS Reality、双 ISP 住宅 ASN）与真实排障手册的深度长文，构建了极度严密的金字塔内链与 SEO 索引安全防护网。

- **十级发布门禁检查**：包含 Build 完整性、Robots 放行、Noindex 误杀、Canonical 自引用、Sitemap 波动监控、内链死链探测、黑客垃圾页面扫描及 Schema.org 语法审计。
- **IndexNow 实时推送**：集成微软 Bing IndexNow 协议，发布时秒级通知搜索引擎爬取最新 URL。
- **高阶权重分层 Sitemap**：依页面战略价值划分权重（`1.0` 首页、`0.9` 核心枢纽、`0.8` 专题聚合、`0.7` 长尾文章），并带有标准的 `YYYY-MM-DD` 最后更新时间戳。

### 4. 极致的前端交互与高转化转化组件
- **矢量遥测大屏 (Hero SVG)**：高科技监控看板，直观展现全球骨干链路 RTT 延迟与 0 丢包率。
- **一键复制优惠券 (`<CopyCoupon />`)**：Vue 3 编写的高效转化组件，支持一键剪贴板复制提示与专属推广渠道直达。
- **Pagefind 客户端离线搜索引擎**：毫秒级多关键词中文分词检索，零服务端依赖。

## 🚀 快速上手 (Quick Start)

### 1. 环境准备
确保本地安装了 **Node.js (>= 18.0.0)** 与 **npm**。

```bash
# 查看版本
node -v
npm -v
```

### 2. 克隆仓库与安装依赖
```bash
# 克隆项目
git clone https://github.com/sksksk98698-source/airpick.co.git

# 进入目录
cd airpick.co

# 安装依赖
npm install
```

### 3. 本地启动开发服务器
```bash
npm run docs:dev
```
启动成功后，浏览器访问终端提示的本地地址（默认 `http://localhost:5173/`）。

为杜绝任何意外造成全站掉收录或死链上线的风险，项目严格实行 **“门禁驱动发布”**：

### 1. 安全一键构建与门禁核验 (推荐)
```bash
npm run build:safe
```
> 此命令等价于：`npm run docs:build && npm run seo:check`。

npm run seo:check

## 🌐 生产环境部署建议 (Production Deployment)

### Apache 部署
- 编译生成的 `docs/.vitepress/dist/` 目录即为静态网站根目录。
- 确保 `docs/public/.htaccess` 放置于根目录下，其内置了：
  - 强制全站 HTTPS
  - 将 `www.airpick.co` 301 规范化重定向至 `https://airpick.co/`
  - 目录缺少尾斜杠自动 301 补齐
  - `cleanUrls` 伪静态无缝映射

### Cloudflare Pages / Nginx 部署
- **构建输出目录**：`docs/.vitepress/dist`
- **构建命令**：`npm run build:safe`
- **Cloudflare WAF 建议**：
  在 Cloudflare 控制台 -> **安全性 -> WAF -> 自定义规则** 中添加：
  - 规则表达式：`(cf.client.bot)`
  - 执行动作：`跳过 (Skip)` -> 勾选所有安全托管规则与 Bot 质询。
  - *作用：确保 Googlebot 与 Bingbot 在抓取高频内容时绝不触发任何验证码或 JS Challenge。*
